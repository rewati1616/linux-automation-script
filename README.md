# Linux Automation Script

A simple and efficient Linux automation project built using Bash scripting to automate repetitive system tasks and improve workflow efficiency. This project helps users perform common Linux operations quickly through command-line scripts.

---

## 🚀 Features

- Automates routine Linux tasks
- Easy-to-use Bash scripts
- Beginner-friendly project structure
- Improves productivity and saves time
- Lightweight and fast execution

---

## 🛠️ Tech Stack

- Bash Shell Scripting
- Linux Terminal
- Shell Commands

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/rewati1616/linux-automation-script.git
```

### Navigate to the project folder

```bash
cd linux-automation-script
```

### Give execute permission

```bash
chmod +x automation.sh
```

### Run the script

```bash
./automation.sh
```
